# A057G-kernelsunext
KernelSU for Samsung Galaxy A05s (SM-A057G)

Project: KernelSU A057G
Device: Samsung Galaxy A05s
Model: SM-A057G
Firmware: A057GXXU7DYE5
Kernel: Stock-based / KernelSU patched kernel

---

FEATURES

- KernelSU support
- Root access through KernelSU Manager
- Stock-based kernel
- Designed for Samsung Galaxy A05s A057G
- Suitable for testing custom ROMs and system modifications

---

INSTALLATION

1. BACK UP YOUR ORIGINAL BOOT IMAGE FIRST.

2. Make sure your device is:
   SM-A057G

3. Make sure your firmware matches:
   A057GXXU7DYE5

4. Flash the provided KernelSU boot image.

5. Reboot the device.

6. Install KernelSU Manager.

7. Open KernelSU Manager and verify that KernelSU is
   detected and working.

---

NO PC / LAPTOP?

If you do not have a PC or laptop, you can use Brokkr,
an Android flashing application with an Odin3-like interface.

Brokkr v2.4.8:
https://github.com/Gabriel2392/brokkr-flash/releases/tag/v2.4.8

WARNING:
Make sure you understand what you are flashing before using
Brokkr or any other flashing application.

You MUST have a USB cable that supports DATA TRANSFER.

Some cheap or generic Chinese USB cables are CHARGING-ONLY
and do NOT support data transfer.

Use an original Samsung cable or another high-quality USB
cable confirmed to support data transfer.

If the phone is only charging and Brokkr cannot detect it,
try a different data-capable USB cable.
